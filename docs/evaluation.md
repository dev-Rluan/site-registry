# 동작·성능·AI 효율 검증

검증일: 2026-10-31. 모든 데이터는 가상입니다.

## 현재 확인한 결과

저장·승인·분석 버전과 실제 HTTP/stdio MCP는 동작합니다. 기존 15개 테스트와 브라우저 흐름은 통과했습니다. 추가로 디스크 SQLite, 로컬 HTTP, 별도 MCP 프로세스를 실행해 아래 성능을 측정했습니다.

실제 AI 호출은 **인증 세션 만료로 중단**됐습니다. Claude Code의 로그인 표시만으로 유효한 API 인증을 확인할 수 없었습니다. `/site` Skill 발견까지 확인했으며, 실제 모델의 답변 품질·토큰·비용·시간 개선은 아직 측정하지 않았습니다. [실제 연결 시도 결과](claude-mcp-smoke.json)를 참고하세요.

## 로컬 성능

Node.js 24.22.1 / macOS arm64 / Apple M2 Pro에서 측정했습니다. 자료마다 3개 버전이 있고, 전체 자료의 70%가 공유 가능한 승인 기준본을 갖도록 가상 데이터를 구성했습니다. 5회 워밍업 후 40회 순차 요청의 p95(95백분위)입니다. 동시 사용자 부하 시험은 아닙니다. 응답 파싱과 경계 검증 시간도 포함합니다.

| 자료 수 / 전체 버전 | Store p95 | HTTP p95 | 실제 stdio MCP p95 |
|---|---:|---:|---:|
| 10개 / 30버전 | 0.348ms | 1.238ms | 0.567ms |
| 100개 / 300버전 | 2.806ms | 3.907ms | 3.791ms |
| 500개 / 1500버전 | 15.760ms | 19.063ms | 17.433ms |

500개 자료에서 MCP 프로세스 시작부터 첫 컨텍스트 수신까지는 p95 **54.956ms**였습니다. 새 프로세스 5회 측정이며 OS 파일 캐시는 이미 따뜻한 상태입니다.

## 전달량

같은 자료 500개에 대해 같은 출력 필드로 비교했습니다.

| 출력 | UTF-8 크기 |
|---|---:|
| 같은 사이트의 전체 1,500버전 | 1,155,943B |
| 승인·공유된 기준본 350개 | 273,897B |
| 사이트·배치·검토 기준까지 포함한 전체 컨텍스트 JSON | 313,758B |
| 실제 MCP 응답 한 줄, 프로토콜·들여쓰기·escape 포함 | 364,094B |

동일 필드 자료 기준으로 **76.305% 감소**했습니다. 가상 데이터의 버전·승인·공유 비율에 따른 선별 효과입니다. 문자/바이트를 모델 토큰으로 환산하거나 업무 시간·비용 절감률로 해석하지 않습니다.

## 경계 검증

- 같은 사이트의 승인·공유본만 전달
- 새 초안·반려본이 있어도 이전 승인 기준본 유지
- 다른 사이트의 자료, 비공유 자료, 암호화된 비밀 원문 제외
- 자료의 ID·버전·출처 보존
- 실제 MCP는 별도 프로세스, HTTP는 실제 로컬 소켓 사용

## 실제 모델 A/B 설계

[evaluation/cases.json](../evaluation/cases.json)에 8개 질문과 생성 모델에 숨기는 채점 기준이 있습니다.

1. 기존 기능 안내
2. 승인 취소 이벤트로 범위 확장
3. 자동 환불 신규 요구
4. 같은 금액·다른 식별자의 중복 오판 방지
5. 다른 사이트 정책 혼용 방지
6. 최신 미승인 초안보다 승인 기준 우선
7. 실제 운영 근거가 없을 때 판단 보류
8. 배치 등록 정보와 실제 실행·성공 구분

같은 모델·공통 지침·질문에 대해, 공유 가능한 전체 버전과 실제 `get_site_context`의 승인본을 비교합니다. 전체 버전에도 승인 상태·출처를 제공하여 의도적으로 불리하게 만들지 않습니다. 평가 전용 DB에 상충하는 v3 초안을 추가하며, 공개 데모와 사용자 DB는 수정하지 않습니다.

두 조건 모두 컨텍스트를 고정 입력하고 도구를 끄는 통제 비교입니다. 기능맵의 본문 중복을 피하려고 이 비교에는 `get_feature_map`을 함께 넣지 않습니다. 실제 `/site`의 MCP 호출·분석 저장 검증은 별도 smoke입니다. 모델의 실제 입출력·캐시 토큰과 전체 경과 시간, CLI의 비용 추정치를 보존하고 자동으로 자가 채점하지 않습니다. CLI 비용 추정은 실제 청구액과 다를 수 있습니다. [공식 CLI 실행 문서](https://code.claude.com/docs/en/headless)

8문항·조건별 1회는 탐색 평가입니다. 향상률에 통계적 유의성이나 일반적인 업무 생산성 주장을 붙이지 않습니다. 의미 기반 답변 채점과 실제 업무 자료 검증은 별도로 필요합니다.

## 재현

```sh
npm test
npm run benchmark
npm run eval:prepare
```

위 세 명령은 모델을 호출하지 않습니다. 벤치마크는 가상 임시 DB를 사용하고 삭제합니다. 준비 검증에서 8문항의 자료 ID/승인 버전과 사이트·비밀값 경계를 확인합니다.

유효하게 로그인한 Claude Code가 있으면 다음 명령으로 실제 모델을 호출합니다. 설정된 계정의 사용량을 소비합니다. 기본 모델은 `sonnet` 별칭이며 실제 모델 식별자는 결과에 저장합니다.

```sh
npm run smoke:claude
npm run eval:claude -- --run
```

A/B는 16회 호출하며 호출당 CLI 비용 추정 상한은 $0.50입니다. smoke는 1회이며 $0.80입니다. 이 상한은 구독 사용량·청구액을 보장하는 제한이 아닙니다. 결과는 `docs/claude-mcp-smoke.json`, `docs/claude-ab-evaluation.json`에 기록합니다. 사용자 메일·키·인증 토큰·원문 세션 로그는 공개 결과에 넣지 않습니다.

## 남은 한계

- 관련 자료를 검색·선별하는 검색기는 없습니다. 사이트 자료가 늘면 승인본 전체가 전달되어 모델 입력량도 늘어납니다.
- Skill이 컨텍스트와 기능맵을 모두 읽으면 기능 본문이 중복될 수 있습니다. 통제 비교의 입력량과 실제 Skill 전체 토큰을 같다고 보지 않습니다.
- 사람의 검토·승인은 사실 정확성을 자동 보증하지 않습니다. 내용 검증은 계속 필요합니다.
- 다중 사용자, 원격 배포, 운영 부하·실제 데이터의 품질은 이번 범위에 포함하지 않았습니다.
