# 검증 결과 캡처

포트폴리오에 삽입할 수 있는 PNG 3장과 편집 가능한 HTML 원본입니다. 모든 업무 자료는 가상입니다.

| 파일 | 내용 | 구분 |
|---|---|---|
| [01-results-overview.png](01-results-overview.png) | 입력 토큰, 응답 시간, 답변 검토 비교 | 실측 JSON 시각화 · 2400×1500 |
| [02-live-mcp-result.png](02-live-mcp-result.png) | 실제 도구 호출 4개와 저장된 분석 #2 v1 | 실행 기록 JSON 시각화 · 2400×1500 |
| [03-saved-analysis-ui.png](03-saved-analysis-ui.png) | Claude가 저장한 분석을 실제 앱에서 조회 | 앱 화면 원본 · 2160×1365 |
| [index.html](index.html) | 요약 2장의 편집 가능한 원본 | 브라우저에서 열기 · 외부 리소스 없음 |

01·02는 기록된 측정값을 읽어 만든 요약 화면입니다. 03은 성공한 실제 테스트 DB를 읽기 전용으로 열고 화면 변경 없이 촬영했습니다. 새로운 AI 호출이나 결과 재측정은 수행하지 않았습니다.

8문항·조건별 1회, AI 보조 채점입니다. 사람 평가·실제 업무 생산성 검증은 하지 않았습니다. 원자료와 해석은 [검증 보고서](../evaluation.md)에 있으며, 이미지 크기와 원자료·이미지 해시는 [manifest.json](manifest.json)에 보존했습니다.
